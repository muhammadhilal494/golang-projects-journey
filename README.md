A command-line task manager built with Go. This is my first project, focused on learning the basics of Go and building a simple terminal interface.

- [x] Display the task manager menu
- [ ] Add a task

- [ ] Mark a task as complete

**Concepts practiced:**
- `package main`
- Importing packages

- Printing output with `fmt.Println()` and `fmt.Print()`
- Git commits and project organization
